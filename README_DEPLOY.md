# EcoLink Zambeze — versão corrigida

Esta versão foi preparada para publicação directa. Os recursos principais também estão na raiz do projecto para evitar erros de caminhos de ficheiros em deployments configurados de forma diferente.

## Publicação

- `index.html` deve ficar na raiz.
- Publique todo o conteúdo desta pasta.
- Se usar Cloudflare Pages via GitHub, use a raiz do repositório como diretório de saída se não houver processo de build.
- Depois do deploy, faça Ctrl+F5.
