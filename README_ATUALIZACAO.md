# EcoLink Zambeze — versão actualizada

## Novidades
- Novo banner vertical "Pensar Grande" incluído no slideshow do login.
- Transição suave entre os slides, com três indicadores.
- Animação no Dashboard com camião EcoLink a deslocar-se até ao ponto de recolha.
- Animação de vários munícipes a entregar materiais ao reciclador.
- Ponto de recolha e reciclador identificados visualmente.
- Mantidos os três níveis de acesso, funcionamento local/offline, câmara, fotografias, pontos e recompensas.

## Executar
Abra `index.html` num navegador moderno.

Para câmara/localização/PWA, prefira servir a pasta por HTTPS ou localhost.

## Cloudflare Pages
Envie o conteúdo desta pasta para o repositório GitHub e publique no Cloudflare Pages. `index.html` deve permanecer na raiz.
